# 能耗规则

以 `src/engineering_facts/rules/energy_conversion_rules.json` 作为唯一确定性折标系数库。

## 核算体系

- 默认使用 `standard_coal`，除非用户、项目画像、模板或上游冻结数据明确要求其他体系。
- 只有明确触发时才使用 `standard_oil`。
- 同一能耗计算表不得混用标准煤和标准油体系。

## 折标边界

- 设备专业数据中识别到的公用工程默认进入本次能耗整理。
- 规则库覆盖且输入物理量、单位、运行小时数充分的介质，直接执行确定性年化与折标。
- 缺少折标系数、缺少物理量、单位不匹配、蒸汽压力/品位不足时，保留公用工程条目并记录未折算原因。
- 只有热负荷、冷负荷或 duty 线索而无实物量时，只保留线索，不反推介质实物量。

## LLM 边界

LLM 写作者不得创建、修改、四舍五入或猜测折标系数。识别并整理出的核算介质不在内置库中时，按 10.5 节 Research 路由处理缺失系数。
