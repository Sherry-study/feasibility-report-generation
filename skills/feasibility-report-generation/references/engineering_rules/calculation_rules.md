# 计算规则

只有当所需输入已存在于确认后的 Engineering Facts 或用户确认输入中时，才执行确定性计算。

## 年化计算

- 年产能 = 小时流量（kg/h）x 年运行时长 / 1000。
- 年物料消耗量采用同一公式。
- 缺少年运行时长时，年化结果保持阻塞，并通过延迟用户输入门一次性提问。

## 财务与投资数据

- 不合成项目总投资、年利润、回收期、IRR 或其他财务指标。
- FA 结果不可用时，按 Schema 显示为待计算或不可用。
- 公开资料不能替代企业项目价格、投资估算、运行成本或融资假设。

## 缺失数据

专业输入缺失时保持显式缺口，不得把缺失值改写成看似合理的正文或近似数字。
